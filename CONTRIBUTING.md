# Contributing

Thanks for contributing to `orca-autoflow`.

## Local Setup

```sh
git clone git@github.com:Munsik-Park/orca-autoflow.git
cd orca-autoflow
go test ./...
```

If your environment blocks the default Go build cache, point `GOCACHE` at a
writable temporary directory:

```sh
GOCACHE=/tmp/orca-autoflow-gocache go test ./...
```

## Development Guidelines

- Keep CLI behavior covered by focused tests in `internal/cli`.
- Keep AutoFlow artifact contracts covered in `internal/autoflow`.
- Do not overwrite user-authored `.autoflow/` artifacts.
- Prefer small changes that preserve the current command surface.
- Update `README.md` and `DOCS.md` whenever user-facing commands or flags change.

## Pull Requests

Before opening a pull request:

```sh
go test ./...
```

Include a short summary, the issue or behavior being addressed, and the commands
used for verification.

## Documentation Assets

README images are generated by:

```sh
go run ./scripts/render-readme-assets
```

Regenerate the assets after changing `scripts/render-readme-assets/main.go`.
